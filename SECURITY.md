# Security

Please do not report an undisclosed vulnerability in a public issue.

Use GitHub's private vulnerability reporting for this repository when available.
Include the affected release or commit, platform, reproduction steps, impact,
and a minimal proof of concept. Redact credentials, personal paths, private
model files, and unredacted diagnostics.

Until a fix is available, avoid sharing exploit details beyond the maintainers.
Security fixes and disclosure timing are coordinated with the reporter. The
local API is intended for localhost use; do not expose it to a network interface
or forward it through a proxy without an explicit security review.
