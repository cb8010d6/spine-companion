# Spine Companion v0.2.5-beta.1

This beta continues the v0.2.5 line by making Manager behave more like a desktop control console.

## Added

- Dashboard is now the default Manager view.
- Dashboard summarizes current model, AI source, bridge/API health, reminders, updates, and renderer health.
- Added quick navigation from Dashboard to Library and AI Integrations.

## Notes

- Debug and diagnostics remain available, but the default entry point is now operational status instead of model browsing or manual testing.
