# Spine Companion v0.2.5-rc.7

This prerelease polishes the Manager for everyday use and fixes theme, localization, and narrow-window issues before the stable release.

## Changes

- Refines the Manager brand area, navigation hierarchy, spacing, and typography.
- Reworks Dashboard into a compact three/two/one-column responsive grid.
- Adds distinct but restrained status tones for models, AI, bridge health, reminders, updates, and rendering.
- Fixes the light theme so all Manager surfaces use the selected palette.
- Keeps the document language, navigation labels, tooltips, and runtime label in sync after a locale change.
- Localizes remaining download, model, recovery, and diagnostics states.
- Restores keyboard focus after closing a modal and gives paired slider/number controls distinct accessible names.
- Allows diagnostic paths and technical details to be selected and copied.
- Collapses navigation safely on narrow windows and stacks Avatar Studio import controls.
- Adds a development-only Manager preview for dark/light and English/Chinese visual checks.
- Adds a test that keeps English and Chinese keys and placeholders aligned.

No copyrighted Spine model assets are included.
