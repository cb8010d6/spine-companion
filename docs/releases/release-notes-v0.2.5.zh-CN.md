# Spine Companion v0.2.5

Spine Companion v0.2.5 是 Tauri 优先桌面陪伴工作流的首个正式版，整合了 0.2.5 RC 周期完成的 AI 集成、运行诊断、本地形象包、干净安装引导和 Manager 视觉升级。

## 主要内容

- **AI 集成：** 检测常用客户端、带备份配置 MCP、一键安装受管理的 Agent 指令、测试实时桥接、显示真实 AI 来源，并在配置失败或中途退出后安全恢复。
- **Manager 控制台：** 在一个面向普通用户的首页查看当前模型、AI 来源、Bridge/API 健康、提醒、更新和渲染器状态。
- **Avatar Studio：** 校验和导入用户拥有版权或使用权的形象包，区分草稿包与可运行 Spine 导出包，原子安装运行资源，并在校验失败时保留原模型。
- **运行稳定性：** 防止桌宠窗口被系统意外最大化或全屏，提供 GPU/WebView 诊断和渲染器恢复入口，默认保留硬件加速。
- **干净安装：** 补齐未配置模型、资源加载失败、启动失败、诊断和发布包 MCP 检查的本地化引导。本仓库和发布包不包含版权 Spine 模型素材。
- **桌面体验：** 使用统一的 Lucide 导航图标、全新原创应用图标、改进 Manager 控件和主题、品牌化 Windows NSIS 安装器，并支持英文/简体中文安装界面。

## 运行时与兼容性

- 推荐使用 Tauri 运行时。
- Electron 保留为 legacy，不再新增功能。
- 继续通过现有 Pixi 6 / Spine 3.8 runtime 支持 Spine 3.8 资源。
- 默认启用硬件加速。如果本机驱动环境需要，用户可以在兼容性设置中手动关闭。
- macOS 包未签名。如果 Gatekeeper 拦截可信来源的包，请按照部署文档中的 macOS 打开说明操作。

## 隐私与素材

- 仓库和发布包不包含 Ark-Models、明日方舟或其他受版权保护的角色素材。
- 修改 AI 客户端配置前需要确认，会自动创建备份，并提供恢复和诊断路径。

## 验证

- RC 周期已通过 Bun 测试、项目检查、MCP 检查、Rust 测试、Tauri 构建、发布包 MCP 冒烟测试和 Windows NSIS 打包验证。
