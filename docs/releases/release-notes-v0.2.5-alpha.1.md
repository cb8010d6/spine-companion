# Spine Companion v0.2.5-alpha.1

This alpha starts the v0.2.5 feature line with deeper AI Integrations.

## Added

- AI Integration cards now expose whether an agent instruction file is present.
- Added generated Agent instruction prompts for Codex, VS Code Copilot, Claude, Cursor, OpenCode, MiMoCode, Roo/Cline, and Gemini-compatible clients.
- Added editable Custom MCP Client template generation with user-provided tool name, source id, and display label.
- Added Tauri bridge commands for custom MCP templates and agent instructions.

## Notes

- This is an alpha milestone for AI integrations only. Manager productization and Avatar Studio remain planned for beta and rc milestones.
