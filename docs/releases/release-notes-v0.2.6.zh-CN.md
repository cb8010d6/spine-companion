# Spine Companion v0.2.6

v0.2.6 是以 Tauri 为主的桌面版本，目标是在不改变 IDE、终端或 AI 工具使用方式的前提下，
让 AI 辅助编程的工作状态清晰可见。

## 重点变化

- **本地工作状态：** 接入的 AI 工具上报工作阶段后，桌宠会将其转换为角色动画、提醒、
  进度气泡和本次会话内的最近状态历史。
- **无需终端的首次使用：** Manager 模型库可以查看模型来源、选择兼容角色，或导入你有权
  使用的 Spine 3.8 模型。应用安装包不包含第三方角色文件。
- **AI 集成：** 检测本地 MCP 客户端，预览并备份配置变更，安装状态上报指引，运行安装包
  MCP 自检，并把第一次真实 AI 工作上报作为独立步骤跟踪。
- **诊断与恢复：** 查看本地 API、renderer、模型和集成健康状态；设置或加载失败时使用
  有界重试和恢复操作。
- **默认本地运行：** 安装包 API 保持在经过验证的 loopback 地址；提醒和最近状态历史只在
  当前应用会话内有效。

## AI 状态边界

Spine Companion 是一眼可见的状态面板，不是 IDE、终端、任务运行器，也不替代 AI 工具。
MCP 配置只是让上报工具可用，并不会自动揭示所有 AI 状态。AI 工具必须在工作阶段主动调用
`companion_report_ai_phase`（或发送本地 HTTP 更新），且 Spine Companion 需要保持运行。
安装包自检只验证 Companion Bridge；完成设置后请启动一个真实任务，确认工具会主动上报
工作中、等待、检查中、成功或失败等阶段。

## 平台与已知限制

- Windows 10/11 x64 是稳定支持目标。
- Linux x64 以及 macOS Intel/Apple Silicon 安装包是未签名预览版，仅用于评估。透明区域的
  原生穿透只在 Windows 实现；其他平台保持可交互回退。
- Avatar Studio 是位于 **设置 > 实验功能** 的**实验性**辅助工具，不声称已经自动完成拆层、
  绑骨、动作制作或 Spine Editor 导出。
- 模型目录可能引用再分发权未经验证的第三方模型。请阅读显示的来源信息，只使用你拥有
  相应权限的模型。
- 更新通道只控制检查和推荐下载链接，应用不会静默安装更新。

## 数据与升级

模型文件、设置和 AI 配置备份保存在每用户数据目录中，设计上会在应用重启或升级后保留。
提醒、当前状态和最近状态历史仅属于当前会话，应用退出后会重置。
