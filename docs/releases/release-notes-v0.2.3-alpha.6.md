# Spine Companion v0.2.3-alpha.6

Experience polish preview after the alpha.5 risk pass.

## Changes

- Adds configurable hitbox padding for better click-through behavior around small or scaled models.
- Makes compatible dragging smoother by reducing drag frame delay.
- Adds configurable device pixel ratio limit for high-DPI displays.
- Improves Manager Settings with hot-applied DPI and hitbox controls.
- Improves Panel switch styling and basic accessibility labels.
- Adds modal keyboard handling in Manager.

## Notes

This prerelease is intended for Windows installer testing first. Electron remains the recommended runtime.
