# Spine Companion v0.2.3-alpha.5

Risk-first maintenance preview.

## Changes

- Adds configurable global shortcut settings with Diagnostics feedback when registration fails.
- Adds delayed background update checks without automatic installation.
- Extends settings validation for shortcut, update, DPI, and hitbox-related options.
- Improves Diagnostics with shortcut/runtime/update context.
- Documents how to open unsigned macOS builds while signing is still deferred.

## Notes

Electron remains the recommended runtime. Tauri remains experimental.
