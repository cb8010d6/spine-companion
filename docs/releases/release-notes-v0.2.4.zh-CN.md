# Spine Companion v0.2.4

这个稳定版把 v0.2.4 候选版本线收成当前推荐日常使用的 Tauri 版本。

## 重点变化

- 增加 GPU/WebView2 恢复入口，同时默认继续启用硬件加速。
- 改进透明桌面区域的鼠标穿透和命中框行为。
- Tauri 拖动在识别出拖动意图后改用系统原生拖动，修复拖动距离和实际移动距离不一致的问题。
- 单击互动和拖动逻辑分离，普通点击仍然能正常播放互动动作。
- 收敛任务、提醒和 AI 来源状态语义。
- 增加 Codex、VS Code、OpenCode、MiMoCode 及兼容客户端的 AI 集成检测、配置和 MCP 测试基础。
- 增加诊断报告导出，便于排查 GPU、WebView、模型、MCP、配置、提醒和近期状态历史。

## 运行时说明

- Tauri 现在是推荐运行时。
- Electron 保留为 legacy 文档路径，不再作为新功能开发目标。
- 硬件加速仍默认开启。若 WebView2 或显卡驱动进入异常状态，请优先使用 Manager 中的恢复入口。
