# Spine Companion v0.2.3-alpha.6

alpha.5 风险收敛后的体验打磨预览版。

## 变化

- 增加可配置鼠标命中区域余量，改善小模型或缩放模型周围的点击穿透体验。
- 降低 compatible 拖拽帧延迟，让拖动更顺。
- 增加高 DPI 显示器的设备像素比上限配置。
- Manager Settings 增加可热应用的 DPI 和命中区域设置。
- 改进 Panel 开关样式和基础无障碍标签。
- Manager 弹窗支持 Esc 关闭和 Tab 焦点循环。

## 说明

此 prerelease 仍优先用于 Windows 安装包测试。Electron 仍是推荐运行时。
