# Spine Companion v0.2.5-rc.1

This release candidate completes the first v0.2.5 feature loop.

## Added

- AI Integrations now include MCP test, agent instruction generation, instruction-file status, and editable custom MCP templates.
- Manager now opens to a Dashboard with current model, AI source, bridge/API health, reminders, updates, and renderer health.
- Avatar Studio now validates and imports local avatar packs.
- Added experimental MCP tools for avatar requirements, job creation, job updates, pack validation, and pack import.

## Boundaries

- Avatar Studio manages local user-owned avatar packs. It does not claim to turn one flat image into a professional Spine runtime rig automatically.
- Without Spine Editor or another legal export path, the app can validate/import intermediate packs or existing `.skel/.atlas/.png` exports only.
