# Spine Companion v0.2.5-alpha.1

这个 alpha 开始推进 v0.2.5 的 AI Integrations 深做。

## 新增

- AI 集成卡片现在会显示是否已经存在 Agent 指令文件。
- 为 Codex、VS Code Copilot、Claude、Cursor、OpenCode、MiMoCode、Roo/Cline、Gemini 兼容客户端生成 Agent 指令提示词。
- Custom MCP Client 支持用户输入工具名称、source id 和显示名称后生成模板。
- 增加自定义 MCP 模板和 Agent 指令的 Tauri bridge 命令。

## 说明

- 这个版本只是 AI 集成 alpha 里程碑。Manager 产品化和 Avatar Studio 会继续在 beta 与 rc 里程碑完成。
