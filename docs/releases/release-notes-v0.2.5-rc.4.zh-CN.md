# Spine Companion v0.2.5-rc.4

本预发布版完成了第一条可用的 Avatar Studio 运行包工作流。

## 变更

- 校验形象 ID、清单路径、骨骼选择、Atlas 引用和贴图文件。
- 明确区分草稿形象包和可运行的 Spine 导出包。
- 将可运行资源原子安装到本地 models 目录。
- 导入成功后立即启用，并热重载桌宠渲染器。
- 校验或安装失败时保留旧模型和当前启用模型。
- Manager 与 MCP 的形象包导入统一使用同一配置目录。
- Manager 提供明确的“安装并使用”和“保存草稿包”操作。
- 为 CI 和 Release 工作流增加 Rust 缓存。

Avatar Studio 只导入用户有权使用的现有 Spine 运行时导出资源，不会声称把单张图片自动转换成专业 Spine 绑定模型。
