# Spine Companion v0.1.1

[English](release-notes-v0.1.1.md) | [简体中文](release-notes-v0.1.1.zh-CN.md)

## Changes

- Fix Windows portable config discovery so `companion.local.json` next to the exe works.
- Add tray controls for status panel visibility, always-on-top, zoom, state switching, and quit.
- Add drag-direction running behavior with left/right mirroring.
- Add reusable `spine-companion-status` skill and AI tool configuration script.
- Add Codex CLI, Claude CLI, Cursor, Claude Desktop, and Claude Code configuration paths.
- Add Chinese documentation and language links.
- Add GitHub Actions for CI and cross-platform release packaging.

## Windows Quick Start

1. Download `spine-companion-0.1.1-windows-x64-portable.exe`.
2. Put `companion.local.json` next to the exe.
3. Double-click the exe.

This release does not include copyrighted Spine model assets.
