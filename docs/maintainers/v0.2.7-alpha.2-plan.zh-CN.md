# v0.2.7-alpha.2 范围与验收草案

状态：准备中，尚未实现或发布。基线为 v0.2.7-alpha.1。

本草案补充 v0.2.7 总计划：根据用户后续决定，Alpha.2 增加实验性基础绑骨。
这不是自动拆层或专业 Spine 模型生成的完整承诺。Alpha.1 发布期间不向 main
合入新功能，不移动已发布标签。

## 独立 PR

### 1. 会话界面可靠性

只读复核已确认以下问题，先补可重复回归测试再修改：

- listSessions 失败时，当前列表保留旧数据但没有错误提示；首次失败可能看起来像
  没有会话。保留已知数据，同时明确提示读取失败并提供重试，不伪造任务失败。
- 会话列表和 Dashboard 周期性重建 DOM，可能丢失键盘焦点。按稳定会话键更新或
  恢复焦点；避免将必要修复扩大为整个 Manager 重构。
- 会话按钮的 listitem 角色覆盖了原生按钮语义，读屏名称缺少 sessionId。
  使用正确列表/按钮层级，让同来源的多个真实会话可以区分。

验收覆盖初次读取失败、有旧数据时失败、恢复重试、30 秒刷新、关注后刷新、连续
状态事件和读屏名称。旧 HTTP/MCP 调用、静音与首次真实上报规则不得退化。

### 2. 基础骨架数据与校验（Experimental）

- 输入为用户有权使用的已分层 PNG / 现有 avatar pack，复用图层的锚点、偏移、
  缩放、排序和路径校验。
- 为用户明确映射的头、躯干、四肢提供基础骨架模板；允许手动指定任意图层。
  不靠文件名猜测就静默绑定，不承诺自动识别所有角色结构。
- 描述骨骼 ID、父级、局部位置/旋转和图层绑定，保持旧 pack 可读取。新增字段和
  schema 版本策略先通过 fixture 验证，禁止旧文件被静默丢字段或破坏。
- 限制骨骼/图层数量，检查重复 ID、环、缺父级、缺图层、非有限数值和路径越界。
  失败保留原文件；保存与预览互不覆盖。优先使用现有原子保存边界。

本阶段是基础刚性图层绑定，不包含自动蒙皮权重、复杂网格变形、IK 自动求解、
自动动作生成或单图拆层。重计算只发生在实验页操作时，不增加桌宠常驻后台任务。

### 3. 骨架编辑与预览（Experimental）

- 在现有 Avatar Studio 内提供骨架树、父级选择、锚点和绑定编辑，不增加一级导航。
- 预览父子旋转与图层跟随，支持恢复初始姿势；编辑产生未保存提示。
- 骨架模板需先预览、确认后保存。明确区分“骨架草稿”“可导入数据”和“已验证
  runtime”，不能将骨架预览成功标为可直接试穿。
- 模块按需加载，离开页面停止预览并释放资源，桌宠仍默认跟随显示器刷新率。

验收使用自有测试图层，覆盖父子坐标变换、缩放后锚点、缺失图层、重开保留数据、
键盘操作、中英文/明暗主题及 800x600 布局。界面 PR 可以单独回滚。

### 4. Spine 导出交接（条件项）

官方已有 [JSON 格式](https://esotericsoftware.com/spine-json-format)、
[数据导入](https://esotericsoftware.com/spine-import)与
[命令行接口](https://esotericsoftware.com/spine-command-line-interface)。
优先复用这些接口，不自己编写二进制 .skel 编译器，也不随应用分发 Spine Editor。

先以项目固定 Spine 3.8 runtime 和版本匹配 fixture 验证基础数据，再由用户配置
合法、兼容的 Spine Editor 完成真实导入/导出验收。不能仅修改版本字符串假装兼容。
调用需显示输入/输出与实际命令，参数数组执行，限制超时并允许取消；输出使用新目录，
不覆盖原始模型，不收集许可密钥。不具备合法 Editor 验收条件时只交付中间包和清晰
提示，不称为完成 runtime 导出，也不阻塞前面三个可独立验收的 PR。

## 发布门槛

- 所有 PR 独立审查；组合后的同一候选提交通过固定工具链、frozen lockfile、依赖
  审计、JS/Rust 测试、lint/type-check/fmt/clippy、MCP 自检和三端打包门禁。
- Windows 安装升级测试继续核对模型、设置、AI 配置和新旧 pack 保留；原生拖动、
  输入穿透、睡眠恢复和 renderer 重启需要实机验收，不能由截图替代。
- Alpha.1 的实际使用反馈优先于实验功能；存在会破坏数据的缺陷则暂停发布。
- Windows 是稳定支持目标，Linux/macOS 仍为 Preview，Avatar Studio 仍为
  Experimental。不增加云同步、遥测、角色商店、本地大型模型或全量 TypeScript 迁移。
- 未完成合法导出验收时，发布说明必须写明基础绑骨能力与不能完成的事项。

版本号仅在准备候选包时更新；本草案不触发 Alpha.2 自动发布。
