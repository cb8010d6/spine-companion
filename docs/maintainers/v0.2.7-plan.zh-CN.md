# v0.2.7 发布计划

状态：开发中。以正式版 v0.2.6 为基线，不提前承诺发布日期。

## 本轮目标

让用户可靠地知道 AI 还在工作、需要处理，还是已上报完成。状态来自客户端主动
上报；Companion 不执行任务，不监控 IDE，也不靠高频 MCP 调用模拟心跳。

Windows 10/11 x64 保持稳定目标；Linux/macOS 保持 Preview；Avatar Studio 保持
Experimental。桌宠默认继续跟随显示器刷新率，不引入本地大型生成模型或后台云服务。

## 分批交付

| PR | 范围 | 关键验收 |
| --- | --- | --- |
| 提醒生命周期 | 取消、替换、到期竞争；临时展示与任务状态分离 | 取消后无迟到提醒；结束恢复当前任务；旧回调不覆盖新状态 |
| 轻量多会话 | 可选 sessionId、事件去重/顺序、关注切换、新鲜度 | B 完成不覆盖 A 工作；旧 id 仍是状态别名；无会话 ID 时明确按来源汇总 |
| 状态可理解性 | 自检/演示/真实上报分开；更新时间与过时提示 | 不把配置成功称为实时连接；长时间没上报不虚构结果；静音仍生效 |
| Avatar 任务锁 | 操作系统文件锁、进程退出释放、并发安全 | 跨进程不丢记录、不按锁文件年龄抢锁、测试有明确超时 |
| 界面打磨 | 共享 token、密度、按钮状态、明暗主题和窄窗口 | 独立 PR，可回滚；不修改渲染、命中、Catalog 或 MCP 协议 |

每个 PR 先写可重复回归测试，再做最小修复。主负责人复核差异与测试后才允许合并；
相关功能合并后的同一个候选提交重新跑完整门禁。

## 版本节奏

1. `v0.2.7-alpha.1`：核心状态与提醒可用，界面改动经独立复核后纳入。
2. 仅在有明确待验证修复时增加 alpha，不为每个 PR 升版本。
3. 功能冻结后发布 `v0.2.7-rc.1`，给用户验证日常使用与从 v0.2.6 升级。
4. 存在可复现阻塞问题则继续修 RC；用户验收及同提交 CI 通过后才发布 `v0.2.7`。

开发 PR 不自行打标签或发布。预览版、正式版均由已审查的 main 提交构建。

## 不进入稳定版范围

- 云同步、账号体系、默认遥测和付费商店。
- 自动拆层、绑骨、Spine Editor 接力以及本地生成模型。
- 全量 TypeScript 迁移、全面换框架或大量新客户端适配。
- 未经实机验收的 macOS/Linux 原生穿透承诺。

后续角色制作优先调研用户主动调用的图片 API，不把生成任务放进桌宠常驻进程。
须单独确认服务商、上传内容、计费提示、密钥安全、取消与下载限制；图片生成成功
不等于得到可用 Spine rig。现有 avatar pack 是交接边界，无需为本版新建公共仓库。
更远期的社区分享可采用类似创意工坊的自愿发布/订阅模型源，不在此版预建云同步设施。

## 验收门槛

- 使用固定 Bun/Rust 工具链及 frozen lockfile；依赖审计、lint、现有类型检查、JS
  测试/覆盖率、项目与 MCP 自检、Vite 构建、Rust fmt/clippy/tests 全部通过。
- 用可控时钟或同步机制测试取消/触发竞争、替换 ID、旧 auto-return、多会话交错、
  重复/迟到事件、显式结束、过时提示、自检不计真实上报和通知去重。
- Windows 安装包测试以公开 v0.2.6 安装包及校验和为基线，确认模型、配置、每模型
  展示参数、窗口状态和 AI 配置保留；不覆盖用户后续修改。
- Manager 在 1440x900、1024x768、800x600 验证中英文、浅色/深色/系统主题；
  Panel 在实际窗口尺寸验证无横向溢出、主要控件可达、键盘焦点可见。
- 同一候选提交通过三端打包与现有 Release workflow；Windows 验证拖动、缩放、
  睡眠恢复、renderer 重启和模型切换。浏览器截图不替代原生实机验收。
- 发布前记录已验证项、未验证项和明确限制。不得用“测试通过”代替用户验收。

状态协议详见 [State, Sessions, and Temporary Displays](../architecture/state-and-sessions.md)。
