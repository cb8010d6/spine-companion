# Spine Companion v0.2.5-rc.9

This prerelease refreshes the Manager and Windows installer so the application feels closer to a polished desktop product without changing the companion runtime behavior.

## Changes

- Replaces placeholder and Unicode navigation symbols with a consistent Lucide icon set.
- Introduces a new original Spine Companion app mark designed to remain recognizable at taskbar and tray sizes.
- Refines Manager navigation, page headers, cards, buttons, inputs, switches, spacing, and responsive behavior.
- Improves both dark and light theme contrast, hierarchy, focus states, and control feedback.
- Adds branded NSIS header and sidebar artwork while preserving the familiar native Windows installer flow.
- Adds English and Simplified Chinese installer language support based on the Windows display language.
- Adds a deterministic Windows brand-asset generator for maintainers.

No copyrighted Spine model assets are included. Existing model, MCP, state, reminder, and rendering behavior remains unchanged in this visual release candidate.
