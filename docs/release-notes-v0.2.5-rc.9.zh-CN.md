# Spine Companion v0.2.5-rc.9

本预发布版集中升级 Manager 和 Windows 安装器的视觉体验，使应用更接近成熟桌面产品，同时不改变桌宠运行逻辑。

## 变更

- 使用统一的 Lucide 图标替换占位符和 Unicode 导航符号。
- 启用全新的原创 Spine Companion 应用图标，在任务栏和托盘的小尺寸下仍保持辨识度。
- 重新调整 Manager 的导航、页面标题、卡片、按钮、输入框、开关、间距和响应式布局。
- 改进深色与浅色主题的对比度、层级、键盘焦点和控件反馈。
- 为 NSIS 安装器加入品牌顶部图和侧图，同时保留用户熟悉的 Windows 原生安装流程。
- 安装器根据 Windows 显示语言支持英文和简体中文。
- 增加可重复生成 Windows 品牌素材的维护脚本。

本版本不包含任何受版权保护的 Spine 模型素材。模型、MCP、状态、提醒和渲染行为在本视觉候选版中保持不变。
