# Spine Companion v0.2.5-rc.7

本预发布版在正式版前集中打磨 Manager 的日常使用体验，并修复主题、多语言和窄窗口布局问题。

## 变更

- 重新整理 Manager 品牌区、导航层级、间距和字体层级。
- 将控制台改为紧凑的三列、两列、单列响应式布局。
- 为模型、AI、连接健康、提醒、更新和渲染状态增加克制但可区分的色彩提示。
- 修复浅色主题只影响部分控件、主体仍保持深色的问题。
- 切换语言后同步文档语言、侧栏文字、工具提示和运行时标签。
- 补齐下载、模型、恢复和诊断中的剩余中英文文案。
- 关闭弹窗后恢复键盘焦点，并为滑块与数字输入提供不同的可访问名称。
- 允许用户选择和复制诊断路径及技术信息。
- 窄窗口下安全收起侧栏，并将 Avatar Studio 导入控件改为纵向布局。
- 增加仅开发环境使用的 Manager 预览，可检查深浅主题和中英文界面。
- 增加中英文键名及占位参数一致性测试。

本版本不包含任何受版权保护的 Spine 模型素材。
