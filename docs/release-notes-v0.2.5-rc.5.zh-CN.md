# Spine Companion v0.2.5-rc.5

本预发布版将 AI 集成改造成面向普通用户的引导式设置工作区。

## 变更

- 将 AI 集成重构为紧凑工具列表与聚焦详情面板。
- 增加“已检测”“已配置”和“需要处理”筛选。
- 按“检测工具、配置 MCP、安装 Agent 指令、实时连接测试”四步引导完成设置。
- 支持一键安装受管理的 Agent 指令，同时保留用户原有的其他内容。
- 更新已有指令文件前创建带时间戳的备份。
- 在 Windows 上采用可回滚的文件替换流程，并保证重复安装不会产生重复内容。
- 保留高级路径和模板入口，但不再让普通用户首先面对底层配置细节。
- 将设置页整理为外观、行为、交互、渲染兼容、诊断和提醒等清晰分组。
- 增加仅开发环境可用的 Manager 预览入口，用于响应式视觉检查。

本版本不会静默修改或重启 AI 工具。用户仍可先确认配置变更，并在界面提示后自行重启对应工具。
