# Spine Companion v0.2.6-rc.3

本次预发布完成了第一版可用的 Avatar Studio 工作流，并用可更新、带完整性
校验的远程模型目录替换了单模型示例。该版本仍是 Windows / Tauri 候选版。

## 主要变化

- Avatar Studio 现在支持创建、编辑、校验、复制、重新打包、删除和导入带版本的
  avatar pack。
- 图层编辑器支持排序、显隐、锚点、偏移、缩放、精确裁切预览、动作映射，以及
  点击问题后定位到对应字段。
- 已包含 Spine runtime 的包可以临时“试穿”。保留、恢复或关闭确认框都会在原生
  后端安全结束试穿会话。
- 模型库支持固定 commit 的目录元数据、SHA-256 校验、Spine 3.8 兼容性检查、
  ETag 缓存、离线回退、单源失败隔离、搜索、来源启停和分页。
- Ark-Models 目录生成器会检查所有直接模型目录；单个目录损坏或不兼容时只记录
  原因，不会阻塞其他有效模型。
- 已打包的 AI 集成图标可以正常显示；自定义集成可使用本地图标和颜色，远程图片
  URL 会被拒绝。

## 素材与版权说明

仓库和安装包不包含 Ark-Models 或《明日方舟》模型文件。目录仅包含元数据与固定
版本的下载地址。下载、使用或再次分发第三方素材前，请自行核对上游条款并取得
必要授权。
