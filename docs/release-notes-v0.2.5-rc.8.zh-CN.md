# Spine Companion v0.2.5-rc.8

本预发布版修复了使用真实 Windows 发布包进行干净安装验收时发现的最后一批问题。

## 变更

- 为桌宠窗口中的未配置模型、资源加载失败、启动失败、首次引导和打开管理器提示补齐中英文。
- 将诊断页直接显示的 Rust 英文消息转换为本地化的模型、快捷键、GPU、TDR 和渲染器状态说明。
- 切换语言后同步桌宠文档语言和首次引导内容。
- 增加发布包 MCP 冒烟检查：直接启动 `spine-companion.exe --mcp`，列出工具、通过实时 API 上报状态、核对来源，并恢复先前状态。
- 验证云端 NSIS 安装包可以正常解包，并且其中的 Tauri 程序可以使用隔离配置目录启动。
- 增加中文干净安装模型提示的回归测试。

本版本不包含任何受版权保护的 Spine 模型。全新安装不会自带模型，并会引导用户打开 Manager。
