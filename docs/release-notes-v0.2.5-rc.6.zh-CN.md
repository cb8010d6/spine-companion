# Spine Companion v0.2.5-rc.6

本预发布版让 AI 集成配置具备持久状态、安全恢复和更清晰的验证流程。

## 变更

- 持久保存每个 AI 工具的连接测试结果，重开 Manager 或应用后仍可查看。
- 只有真实修改配置或指令后才标记“需要重启”。
- 集成内容变化时自动清除已经失效的旧测试结果。
- 在连接测试前加入清晰的“我已重启该工具”步骤。
- 配置和安装指令完成后显示路径、备份和下一步，不再只显示笼统提示。
- 配置或测试失败时提供重试和打开配置入口。
- 增加受保护的“恢复先前 MCP 配置”操作。
- 恢复前使用 SHA-256 校验当前文件和备份；检测到用户后续修改时拒绝覆盖。
- 使用持久事务日志；如果应用在写配置和提交状态之间退出，下次会自动对账恢复。
- 串行处理集成状态修改，并拒绝在较新配置变更后写入已经过期的连接测试结果。
- 恢复时为被替换的配置保留安全副本。
- 将打开配置、测试、恢复和重启确认等命令限制为只能由 Manager 窗口调用。

集成运行状态单独保存在 Spine Companion 配置目录中，不会把第三方客户端配置内容复制进状态文件。
